## 📖 Descrição do problema real
Muitos estudantes enfrentam dificuldades para organizar sua rotina de estudos, o que resulta em procrastinação, acúmulo de tarefas e baixa produtividade. A falta de um sistema simples de planejamento dificulta o acompanhamento do que precisa ser estudado diariamente.

---

## 💡 Proposta da solução
Este projeto consiste em um **Organizador de Estudos em linha de comando (CLI)**, que permite ao usuário cadastrar, visualizar e gerenciar suas tarefas de estudo de forma simples, rápida e eficiente, auxiliando na organização da rotina.

---

## 🎯 Público-alvo
- Estudantes do ensino médio e superior  
- Pessoas com dificuldade de organização de rotina  
- Usuários que preferem ferramentas simples via terminal  

---

## ⚙️ Funcionalidades principais
- Adicionar tarefas de estudo  
- Listar tarefas cadastradas  
- Marcar tarefas como concluídas  
- Remover tarefas  
- (Opcional) Salvar dados em arquivo local (JSON/TXT)

---

## 🛠 Tecnologias utilizadas
- Python 3.x

- JSON (caso usado para persistência de dados)  
- pytest (testes automatizados)
